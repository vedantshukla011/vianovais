How to Run It

    

      

        
⬇️

        
Download the Script

        
Click the Download button above after generating your script. Save it somewhere easy to find like your Desktop.

      

      

        
⌨️

        
Open Command Prompt

        
Press Win + R, type cmd, hit Enter. Navigate to where you saved the file:

        cd C:\Users\YourName\Desktop
      

      

        
🚀

        
Run the Script

        
Type the command below and press Enter. Chrome will open automatically.

        python whatsapp_sender.py
      

      

        
📱

        
Scan QR Code

        
WhatsApp Web will open in Chrome. Open WhatsApp on your phone → Linked Devices → Scan QR Code. You only need to do this once.

      

      

        
⚡

        
Watch It Run

        
The script will automatically open each contact, pre-fill your message, and click Send. Watch the terminal for live status updates.

      

      

        
📊

        
Review Summary

        
When finished, a summary shows how many messages were sent successfully and lists any numbers that failed.
