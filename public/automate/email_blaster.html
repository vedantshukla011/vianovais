How to Run

    

      

        
🐍

        
Install Python

        
Download from python.org/downloads. During install, check "Add Python to PATH".

      

      

        
📦

        
No Extra Libraries!

        
This script uses Python's built-in smtplib — no pip install needed at all.

        python --version
      

      

        
🔑

        
App Password Setup

        
For Gmail: Google Account → Security → 2-Step Verification → App Passwords. For Yahoo: Account Security → App Passwords.

      

      

        
⬇️

        
Download & Run

        
Generate script above, download it, open Command Prompt in the same folder.

        python email_sender.py
      

      

        
⚡

        
Watch It Send

        
Terminal shows live status for every email — sent ✓ or failed ✗ with the reason.

      

      

        
📊

        
Summary Report

        
After all emails are sent, a full report shows success count, failures, and which addresses failed.
